The one real trade-off

Amber is already a status colour in this app. Today caution is yellow and warn is orange — make the brand amber too and a "QC pending" chip starts to look like furniture rather than a warning. Handled three ways above: the brand sits at #FFB347 (lighter, peachier), warn is pushed toward red-orange #FF8C00 → #A34A00/#FFA14A, and success moves to the set's green-yellow #ADFF2F so the most-scanned state in the fleet table is a different hue entirely. Every chip still carries its text label, so hue is reinforcement, never the only signal.
