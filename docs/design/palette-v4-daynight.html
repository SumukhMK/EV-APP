One decision left — the primary button in dark

If dark is purely purple and grey, the brand colour changes between modes: orange by day, purple by night. That is legitimate, but it does mean "the button you press to commit" is a different colour depending on the time of day. The alternative keeps one amber thread running through both.

1 — purple primarybrand shifts per mode
2 — amber primary, purple everything elseone brand thread
My read: option 2. Purple still owns links, nav and charts so the dark mode still reads as Nocturne, but "Finalise deboard" is the same amber in both modes — and on this app the commit button is the one thing that should never be ambiguous. Option 1 is the cleaner theory; option 2 is the safer product.
